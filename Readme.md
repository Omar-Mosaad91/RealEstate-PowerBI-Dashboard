## 🌟 Project Overview / نظرة عامة على المشروع
مشروع تحليلي متكامل لإدارة وتقييم الأداء المالي والعقاري لشركات التطوير العقاري عالمياً. يهدف هذا النظام إلى تمكين صانعي القرار من متابعة حجم المبيعات، توزيع العقارات حسب الأنواع والمناطق الجغرافية، تحليل المصروفات، وتقييم أداء فريق المبيعات والوسطاء عبر لوحات تفاعلية (Dashboards) مصممة باحترافية عالية.

## 📊 Dashboard Sections / أقسام لوحة القيادة

### 1. Cover / الغلاف الرئيسي
* **الوصف:** الواجهة الترحيبية للمشروع بتصميم فاخر يعكس هوية النظام (Your Gateway to Luxury Properties Worldwide).
* **المحتوى:** زر تفاعلي للاستكشاف (`Explore`) مع استعراض سريع لبعض العقارات المميزة.

### 2. Home (Overview) / الصفحة الرئيسية ونظرة عامة
* **المؤشرات الرئيسية (KPIs):** إجمالي المبيعات ($96.2M)، إجمالي المصروفات ($29.6M)، صافي الربح ($66.6M)، وعدد العقارات المباعة (160 عقار).
* **الرسومات والمخططات:**
  * رسم بياني لمقارنة المبيعات الشهرية (`Total Sales by Month`).
  * تحليل المبيعات حسب قنوات البيع (`Total Sales by Means of Sales`: وسيط، مباشر، أونلاين).
  * خريطة تفاعلية (`Globe Map`) وجدول تفصيلي لحركة العقارات والبلدان مع حالة الدفع (`Payment Status`).

### 3. Sales & Clients Analytics / تحليل المبيعات والعملاء
* **المؤشرات الرئيسية:** إجمالي المبيعات، إجمالي العملاء (12 عميل)، متوسط سعر العقار، وعدد العقارات المباعة.
* **الرسومات والمخططات:**
  * جدول أداء العملاء/المندوبين (`Clients & Sales Table`) مرفق بالصور الشخصية وحجم المبيعات لكل مندوب (`Olivia Taylor`, `Jane Smith`, `Michael Johnson`, إلخ).
  * توزيع المبيعات حسب نوع العقار (`Total Sales by Type`: Condo, Single Family, Apartment, Townhouse).
  * خط زمني لتتبع أداء المبيعات على مدار العام.

### 4. Property Portfolio & Characteristics / محفظة العقارات والخصائص
* **المؤشرات الرئيسية:** إجمالي العقارات (200 عقار)، متوسط سعر العقار ($586.5K)، متوسط مساحة العقار (1522 قدم مربع)، ومتوسط عدد الغرف (3 غرف).
* **الرسومات والمخططات:**
  * مخطط دائري يوضح توزيع أنواع العقارات (`Property Type Distribution`: Townhouse, Single Family, Condo, Apartment).
  * متوسط أسعار العقارات بناءً على عدد الغرف (`Avg Property Price by Bedrooms`).
  * متوسط الأسعار حسب نوع العقار (`Average Price by Property Type`).
  * ترتيب الدول من حيث عدد العقارات المباعة (`Sold Properties by Country`: اليابان، فرنسا، الهند، البرازيل، إلخ).

### 5. Financial & Expense Breakdown / التفاصيل المالية والمصروفات
* **المؤشرات الرئيسية:** إجمالي المبيعات ($25.5M)، إجمالي المصروفات ($8.7M)، صافي الربح ($16.8M)، وهامش الربح (52%).
* **الرسومات والمخططات:**
  * مقارنة تفصيلية بين الإيرادات والمصروفات عبر الزمن (`Revenue vs Expenses`).
  * تحليل المصروفات حسب الفئات (`Expenses by Category`: ضرائب العقارات، أعمال الصيانة، التجديدات والتشطيبات).
  * ترتيب الربحية حسب المواقع الجغرافية (`Profit by Location` مثل مومباي، ساو باولو، مكسيكو سيتي، طوكيو، برلين، باريس، روما).

## 🛠️ Key Features / المميزات الرئيسية
* **تفاعل متقدم (Interactivity):** فلاتر ديناميكية للتحكم في العرض حسب الشهر، السنة، نوع المصروف، وننوع العقار.
* **تصميم مرئي مميز (UI/UX):** استخدام لوحة ألوان داكنة أنيقة (Dark Theme) تناسب قطاع العقارات الفاخرة مع بطاقات مؤشرات واضحة.
* **شمالية البيانات:** ربط البيانات المالية، الجغرافية، وسلوك العملاء في مكان واحد لسهولة اتخاذ القرار.

## 🚀 How to Use / كيفية الاستخدام
1. قم بفتح ملف لوحة القيادة باستخدام برنامج **Power BI Desktop**.
2. تأكد من ربط مصدر البيانات (Data Source) في حال رغبتك بتحديث الأرقام أو ربطها بقاعدة بيانات حقيقية.
3. استعرض الصفحات المختلفة عبر القائمة الجانبية (Sidebar Navigation) للتنقل بين نظرة عامة، المبيعات، العقارات، والتقارير المالية.
